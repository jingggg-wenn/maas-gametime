= 소개: Infrastructure-as-a-Service의 숨겨진 비용

인프라가 명확한 가드레일 없이 셀프 서비스로 제공될 경우, 여러 문제가 빠르게 발생할 수 있습니다:

- 팀들이 GPU 리소스를 올바르게 요청하고 크기를 산정하는 데 어려움을 겪습니다
- 여러 팀이 동일한 모델을 배포하여 노력이 중복됩니다
- 고가의 GPU가 유휴 상태로 남거나 과부하 상태가 됩니다
- 명확한 책임 소재 없이 인프라 비용이 증가합니다
- 개발자에게 필요한 것은 모델 접근이지, GPU 관리의 복잡성이 아닙니다

== Models-as-a-Service: AI 대규모 운영을 위한 효율적인 추상화

이러한 과제를 해결하기 위해 플랫폼 엔지니어로서 중앙 집중화되고, 재사용 가능하며, 안전한 모델 서빙 계층을 설계합니다:

**중앙 집중식 모델 관리**

* 플랫폼 팀이 적절한 라이프사이클 관리를 통해 모델을 배포하고 유지 관리합니다
* 버전 관리, 롤백, 테스트가 표준화된 프로세스로 운영됩니다

**보안 API Gateway**

* 모든 모델 접근이 인증되고 속도 제한이 적용된 엔드포인트를 통해 이루어집니다
* 모든 모델 상호 작용에 대한 완전한 관측성(Observability) 및 모니터링이 제공됩니다

**개발자 친화적 접근**

* 개발자가 기반 하드웨어를 관리하지 않고 모델을 사용합니다
* 팀이 AI 기반 애플리케이션, 에이전트 및 기능 개발에 집중할 수 있습니다

**효율적인 리소스 활용**

* GPU 리소스가 조직 전체에서 풀링되고 공유됩니다
* 공정한 접근 및 비용 통제를 보장하면서 낭비를 제거합니다
